What this skill tests

This skill is about comparing quantities. You set up and solve proportions, use rates such as speed, density, and unit price, scale a ratio up or down, and convert between units by multiplying conversion fractions so the unwanted units cancel. Many questions are word problems with several steps, so writing the units beside each number keeps the setup honest.

How it shows up on the SAT

Mostly word problems, as multiple choice or a typed-in answer.
