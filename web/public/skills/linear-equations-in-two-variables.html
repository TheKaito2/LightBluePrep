8 question types

Every question here is sorted by how you solve it. Pick one type and practice it until it sticks.

  • Plug in a value and solve24 questionsSubstitute the known amount into the given equation, then solve the one-step equation for the other variable.
  • Connect a line to its table or graph24 questionsFind slope and y-intercept from points, then write y = mx + b, or test each choice or table row.
  • Find the slope or intercept21 questionsRewrite as y = mx + b, or set x = 0 or y = 0, or use rise/run from two points.
  • Parallel and perpendicular lines18 questionsParallel: same slope. Perpendicular: negative reciprocal. Put in slope form first, then use the point.
  • Interpret a number in the equation14 questionsMatch each term to what it counts: coefficient x variable = a subtotal, constant = the total.
  • Write the equation from a word problem14 questionsEach term is price (or rate) x count; add the terms and set equal to the total.
  • Find the missing constant or coordinate8 questionsFind the line first, then substitute the point to solve for the unknown.
  • Read a word-problem graph7 questionsIntercepts show all of one item or the other; use them to get prices, totals, or a missing amount.
