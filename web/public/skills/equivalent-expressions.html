What this skill tests

Equivalent Expressions tests algebraic rewriting: combining like terms, expanding products, factoring, and simplifying exponents, radicals, and rational expressions. Many questions ask which choice is equivalent to a given expression, or ask for the constant that makes two forms equal. Expanding each choice, or matching coefficients term by term, settles most of them.

How it shows up on the SAT

Mostly multiple choice with algebraic answer choices; some ask for a constant as a typed-in answer.
