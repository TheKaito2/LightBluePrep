8 question types

Every question here is sorted by how you solve it. Pick one type and practice it until it sticks.

  • Build or use an exponential model47 questionsStart value times growth factor (1 plus or minus rate) to the number of periods; match exponent to period.
  • Read intercepts, zeros and graph features45 questionsSet x or y to 0, treat factors as zeros, or read values straight off the graph.
  • Interpret a number or point in context40 questionsMatch x and y to their meaning, then say what the value, intercept, constant or vertex stands for.
  • Plug in a value or solve for the input34 questionsSubstitute the given input, or set f(x) equal to the output and solve for x.
  • Find an unknown constant or equation27 questionsPlug known points, the vertex or table values into the form to solve for the unknowns.
  • Shift a graph or rewrite equivalent form25 questionsReplace f(x) with f(x) plus c or f(x plus c); rewrite so the target value shows as a number.
  • Find a minimum, maximum or vertex24 questionsUse vertex form, -b/2a, or the midpoint of the roots; a vertical shift moves only the output.
  • Set up and solve a word-problem equation16 questionsDefine the variable, write the area, product or formula as an equation, factor or solve, keep the valid root.
