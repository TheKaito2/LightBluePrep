8 question types

Every question here is sorted by how you solve it. Pick one type and practice it until it sticks.

  • Find an expression's value without solving32 questionsSpot the chunk or scale factor (like 3x or x+6) and multiply or substitute instead of solving for x.
  • Solve a linear equation for x24 questionsDistribute, combine like terms, then undo operations to isolate the variable.
  • Solve a word problem with a rate or total18 questionsSubtract the fixed part, then divide by the per-unit amount to get the answer.
  • Turn a situation into an equation13 questionsName the unknown, translate each phrase into math, and add up the parts to match the total.
  • Find the constant for no or infinite solutions12 questionsMatch the x-coefficients; equal constants give infinitely many, unequal constants give no solution.
  • Pick the equivalent equation5 questionsDo the same operation to both sides of the given equation and match the result to a choice.
  • Count solutions (none, one, infinitely many)5 questionsSimplify both sides: same slope and same intercept is infinite, same slope only is none, else one.
  • Interpret a number in a context equation3 questionsMatch each term of the equation to the story; the coefficient is the per-unit amount.
